You are an experienced Python full-stack developer.

I want to develop a Student Feedback Management System as part of an AI-assisted software engineering assessment.

Objective:
Build a simple web application that allows students to submit course feedback and allows administrators to view and analyze feedback.

Mandatory technology stack:

- Python
- Streamlit
- SQLite
- Python Virtual Environment
- Git

Mandatory functional requirements:

1. Submit Feedback:

- Student Name
- Course Name
- Rating (1–5)
- Comments

2. View Feedback Records:

- Display all submitted feedback in a table.

3. Average Rating:

- Calculate the overall average rating.

4. Highest Rated Course:

- Identify the course with the highest average rating.

5. Course-wise Rating Summary:

- Display each course's total feedback and average rating.

Database requirements:

- Database: feedback.db
- Table: feedback
- Columns: feedback_id, student_name, course_name, rating, comments.

Do not start coding yet. Provide a clear requirement analysis, proposed application structure, and implementation plan.

Now design the SQLite database for the Student Feedback Management System.

Requirements:

1. Create a database named feedback.db.
2. Create a table named feedback.
3. Include these columns:

- feedback_id INTEGER PRIMARY KEY AUTOINCREMENT
- student_name TEXT NOT NULL
- course_name TEXT NOT NULL
- rating INTEGER NOT NULL with a CHECK constraint between 1 and 5
- comments TEXT

Create a separate Python file named database.py.

Implement these functions:

- create_table()

- get_all_feedback()

- get_highest_rated_course()

Use sqlite3, parameterized SQL queries, proper connection handling, and commit changes when inserting records.

Keep the code simple and beginner-friendly.

Create the actual database.py file and explain how to execute it.
